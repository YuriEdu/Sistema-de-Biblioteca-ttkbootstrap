**Sistema de Biblioteca**

Com o objetivo de gerenciar o cadastro e o empréstimo de livros.

Requisitos propostos pelo professor: 
  Cada livro deve possuir: 
    - Código, título, autor e status (disponível/emprestado). 
    - Menu com opções: cadastrar, listar, emprestar, devolver, salvar e sair. 
    - Os dados devem ser persistidos em arquivo .json. 
    - Controlar o número de dias de empréstimo e multas.
